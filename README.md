# AlfaOmega — сайт-визитка

Статическая адаптивная реализация на HTML, CSS и JavaScript. Внешние библиотеки и сборка не требуются. Google Fonts используется для типографики; при отсутствии интернета включатся системные запасные шрифты.

## Запуск локально
1. Распакуйте архив.
2. Откройте `index.html` в браузере. Для более корректной работы можно запустить локальный сервер:
   - Python: `python -m http.server 8000`
   - Затем откройте `http://localhost:8000`.
3. Проверьте мобильное меню, поиск (Ctrl/Cmd + K), подбор формата, копирование ответов, этапы кейса, фильтры FAQ и модальные окна.

## Публикация
Загрузите содержимое папки на любой статический хостинг (например, GitHub Pages, Netlify, Cloudflare Pages или ваш веб-хостинг). Привяжите домен в панели выбранного провайдера и настройте HTTPS.

## Контакты
Контактные кнопки ведут на `https://t.me/holinmoder`. Имя в тексте: Макар. Телефон и email не указаны.

## Что реализовано
- Девять навигационных разделов;
- адаптивная вёрстка для мобильных и настольных экранов;
- поиск по разделам с Ctrl/Cmd + K, клавиатурная навигация и Esc;
- подбор формата по трём вопросам, резюме ответов и копирование;
- пять переключаемых этапов кейса;
- FAQ с поиском, категориями и раскрывающимися ответами;
- модальные окна для двух форматов;
- Telegram-ссылки и переходы по странице.

## Что требует отдельного подключения/материалов
- **Фотографии, логотипы, скриншоты и оригинальные отзывы:** исходные медиа не включены автоматически. Добавьте только материалы, которыми разрешено пользоваться, в `assets/images` и разметьте их в `index.html`.
- **Реальная форма заявок/CRM/уведомления:** сейчас контакт происходит через Telegram. Для записи заявок в базу, отправки email или CRM нужен серверный endpoint и ключи доступа.
- **Партнёрские программы:** ссылки/виджеты конкретных компаний подключаются после получения официальных URL, разрешений и необходимых идентификаторов.
- **Аналитика:** подключается отдельно с учётом согласия пользователей и требований законодательства.
- **Личный кабинет/авторизация/платежи:** в открытой статической версии не реализованы; необходим backend и спецификация API.

## Важные примечания
Это самостоятельная реализация доступных интерфейсных сценариев, а не копия исходного backend. Тексты кейсов и доходов намеренно не воспроизводят непроверенные утверждения референса как факты: используйте подтверждённые материалы и необходимые дисклеймеры. Перед публичным запуском проверьте актуальность условий, юридические требования и все внешние ссылки.


## Визуальная доработка
В этой версии обновлены навигация, hero-композиция, карточки основателя, партнёрский блок, сетка и типографика в сторону исходного AlfaOmega. Портрет Макара не подменён фотографией другого человека: вместо этого использован фирменный графический блок. Чтобы добиться ещё большей точности, можно добавить собственный портрет и оригинальные изображения кейса.


Палитра в этой редакции нейтрализована: убраны лаймовые акценты, добавлены сдержанные светлые и серые тона. Это исправляет предыдущий стилистический промах, но без точного визуального сравнения в браузере не следует считать её точным совпадением с оригиналом.
